Managed Preferences

Reference for the JAMF/MDM-managed preferences consumed by esumdm. These keys are read from /Library/Managed Preferences/io.enterprisesoftwareupdate.esumdm.plist, typically delivered via a configuration profile.

Preference Domain: io.enterprisesoftwareupdate.esumdm

deadline

Deadline to Update macOS.

Date

Macs past this date will be forced to install the update. Users will see increasingly urgent prompts as the deadline approaches.

<key>deadline</key>
<date>2025-12-31T12:00:00Z</date>

deadline_hide_timezone

Hide Deadline Time Zone.

Boolean

When true, the time-zone abbreviation is omitted from deadline timestamps shown to end users.

<key>deadline_hide_timezone</key>
<false/>

deadline_show_in_local_time

Show Deadline in Local Time.

Boolean

When true, deadlines shown to end users are rendered in the Mac's local time zone rather than UTC.

<key>deadline_show_in_local_time</key>
<false/>

force_gui_install

Force GUI Install.

Boolean

When true, the macOS update is performed via the native Software Update UI rather than the command-line installer. Users will need to interact with the GUI to complete installation.

<key>force_gui_install</key>
<false/>

helpdesk_message

Helpdesk Message.

String (Required)

Shown to users when they need assistance or encounter an error.

<key>helpdesk_message</key>
<string>Contact the Helpdesk at (800) 555-1212 for assistance.</string>

license_file

License File.

String

Absolute path to the Keygen license file. Typically supplied via CLI rather than MDM.

<key>license_file</key>
<string>/Library/Application Support/io.enterprisesoftwareupdate/license.lic</string>

log_level

Log Level.

String

Controls the verbosity of esumdm log output. Typical values are debug, info, warn, or error.

<key>log_level</key>
<string>info</string>

mode

Operation Mode.

String

Selects what esumdm does. "macos_update" (the default when unset) applies minor macOS updates. "third_party" runs the preflight/postflight Jamf arrays without performing a macOS update. "macos_upgrade" is reserved for future major-version upgrades and is not yet implemented.

<key>mode</key>
<string>macos_update</string>

networkquality_disabled

Disable Network Quality Check.

Boolean

When true, skips the internet-speed test before downloading the update.

<key>networkquality_disabled</key>
<false/>

org_logo_path

Organization Logo Path.

String (Required)

Absolute path to a logo image shown in UI prompts. Administrators must place the logo on the Mac filesystem before deploying ESUMDM. Recommended permissions are world-readable (e.g. 664).

<key>org_logo_path</key>
<string>/usr/local/org/logo.png</string>

org_name

Organization Name.

String (Required)

Displayed in UI prompts to end users to identify the managing organization.

<key>org_name</key>
<string>My Org Name</string>

postflight_disabled

Disable Postflight Sequence.

Boolean

When true, the postflight Jamf policy sequence is skipped entirely.

<key>postflight_disabled</key>
<false/>

postflight_forced

Force Postflight Sequence.

Boolean

Ensures postflight policies run even if the update was installed outside of ESUMDM (e.g. via native Apple Software Update methods).

<key>postflight_forced</key>
<false/>

postflight_jamf_array

Postflight Policy Array.

Array

A list of Jamf custom triggers to run after the OS update. Each element follows the format "User-Facing Text,trigger_name" and will only execute if a Jamf policy is scoped to that trigger.

<key>postflight_jamf_array</key>
<array>
	<string>Installing Post-Update 1,post_event1</string>
</array>

preflight_disabled

Disable Preflight Sequence.

Boolean

When true, the preflight Jamf policy sequence is skipped entirely.

<key>preflight_disabled</key>
<false/>

preflight_jamf_array

Preflight Policy Array.

Array

A list of Jamf custom triggers to run before the OS update. Each element follows the format "User-Facing Text,trigger_name" and will only execute if a Jamf policy is scoped to that trigger.

<key>preflight_jamf_array</key>
<array>
	<string>Updating Software Title 1,pre_event1</string>
</array>

target_minos_version

Minimum Minor OS Version.

String

The minimum macOS version ESUMDM should enforce. For example, 15.7.2 on a macOS 15.x Mac. Required in "macos_update" mode.

<key>target_minos_version</key>
<string>15.7.2</string>

third_party_deadline_receipt

Third-Party Deadline Receipt.

String

Base name for the third_party workflow's state receipts; esumdm appends ".started.bom" (resume marker) and ".complete.bom" (work-done gate) to it. Provide a bare base name with no ".bom" extension. Required in "third_party" mode.

<key>third_party_deadline_receipt</key>
<string>acme-onboarding</string>

third_party_no_reboot

Disable Third-Party Reboot.

Boolean

When true, esumdm does not reboot the Mac at the end of the third_party workflow.

<key>third_party_no_reboot</key>
<false/>
