Strings

Reference for the user-facing strings shown by esumdm. These keys are read from /Library/Managed Preferences/io.enterprisesoftwareupdate.esumdm.custom.plist, typically delivered via a configuration profile. Any key that is omitted falls back to the default shown in its example.

Placeholders such as %s and %q are filled in by esumdm at display time; keep them in the same order when customizing a string.

The values shown in the examples are the defaults; customize them to suit your environment.

Preference Domain: io.enterprisesoftwareupdate.esumdm.custom

Authenticate

Authenticate.

String

Password prompt shown before installing. %q is the signed-in user's name.

<key>Authenticate</key>
<string>Enter the password for %q:</string>

AuthenticateOtherUser

Authenticate Other User.

String

Password prompt shown when the signed-in user lacks a secure token and another user's password is required. The first %s is the signed-in user; %q is the secure-token user.

<key>AuthenticateOtherUser</key>
<string>The current signed-in user %s does not have a secure token. Please enter the password for %q:</string>
